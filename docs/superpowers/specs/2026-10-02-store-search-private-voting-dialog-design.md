# 店家搜尋、私人投票與內建提示設計

日期：2026-10-02

## 店家搜尋

- 地圖搜尋列只查詢 BiteMap 已發布且具備地圖資料的店家。
- 搜尋「7-11」只顯示資料庫中名稱符合的店家，例如「7-11 中原」。
- 不再在地圖搜尋列顯示外部地理編碼的地區或地址結果。

## 私人約飯投票

- 私人約飯沿用公開約飯的候選餐廳、正式成員一人一票、改票與確認結果流程。
- 私人約飯只有發起人與正式成員可查看投票內容及投票數；待審核者不能投票。
- 同票確認時，系統只在最高票的平手候選中隨機選擇。

## 內建提示

- 提前開始投票前顯示 App 內建 Dialog，說明開始後飯局會成團，其他人不能再加入。
- 同票確認前顯示 App 內建 Dialog，說明系統會在平手候選中隨機選擇。
- 解除好友使用相同的 App 內建 Dialog，取消時不送出 API。
- 不使用瀏覽器 `window.confirm`。

## 驗證

- 地圖搜尋不回傳或顯示地區／地址結果。
- 公開與私人約飯都能完成候選、投票與結果確認流程。
- 三種 Dialog 的取消與確認行為正確，並通過前端與後端相關測試。
