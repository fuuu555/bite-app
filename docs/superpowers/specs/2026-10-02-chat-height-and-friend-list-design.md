# 聊天高度與好友名單設計

日期：2026-10-02

## 目的

減少聊天室訊息較少時的底部空白，並讓好友社交中心的好友名單維持精簡。

## 聊天室

- 聊天面板以可視區域作為高度上限；訊息區在其內部捲動，輸入列固定接在面板底部。
- 訊息不足以填滿面板時，訊息區依內容高度呈現，不預留額外的大面積空白。
- 訊息超過可視區域時，保留既有的歷史訊息載入、捲動位置與新訊息提示行為。

## 好友名單

- 好友社交中心預設只顯示前 3 位好友。
- 好友超過 3 位時，列表底部顯示「查看更多」按鈕。
- 點擊後顯示所有好友，按鈕改為「收合」；再次點擊回到前 3 位。
- 好友數量不超過 3 位時不顯示切換按鈕。

## 驗證

- 聊天 UI 在桌面與手機寬度不出現輸入列下方的大面積空白。
- 4 位以上好友可在展開與收合之間切換；3 位以下沒有切換按鈕。
- 前端 lint、typecheck 與既有測試通過。
