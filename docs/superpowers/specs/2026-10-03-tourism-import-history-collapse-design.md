# 觀光署匯入紀錄收合設計

## 目標

觀光資料匯入完成後，歷史執行紀錄會持續佔據管理頁面空間。讓管理員能收起紀錄，同時保留主要匯入操作的可見性。

## 介面行為

- 「觀光署資料整合」標題、說明與「一鍵匯入最新資料」按鈕始終顯示。
- 只收合／展開匯入紀錄清單，不隱藏整個整合區塊。
- 紀錄清單旁提供可操作的展開／收合圖示，並更新無障礙名稱與 `aria-expanded` 狀態。
- 匯入完成或部分失敗、完成結果提示框關閉後，自動收合紀錄清單；進行中的匯入不自動收合。
- 管理員可隨時手動展開查看既有紀錄。
- 沒有紀錄時不顯示收合控制。

## 範圍外

- 不刪除或改變匯入紀錄資料。
- 不改變匯入觸發、輪詢、結果提示或資料重新載入流程。
- 不增加跨頁面保存收合狀態的需求。

## 驗收條件

1. 匯入區塊標題與匯入按鈕在收合時仍可見及操作。
2. 收合時紀錄清單不佔版面；按展開控制可再次檢視。
3. 完成匯入並關閉結果提示後，紀錄清單自動收合。
4. 匯入仍在執行時，紀錄不會因輪詢而自動收合。
